7DaysOfCode - Desafio Alura

##Português - BR

Este repositório foi criado para documentar meu progresso no desafio 7DaysOfCode, proposto pela Alura
(https://www.alura.com.br/).

O objetivo do desafio é desenvolver, ao longo de 7 dias, uma aplicação CRUD utilizando Java, Spring Boot e suas dependências.

Durante esse período, compartilharei diariamente minha evolução, os conhecimentos adquiridos e as implementações realizadas em cada etapa do desafio.

##English - US

This repository was created to document my progress in the 7DaysOfCode challenge, proposed by Alura(https://www.alura.com.br/).

The goal of this challenge is to build a CRUD application over the course of 7 days using Java, Spring Boot, and its dependencies.

Throughout this journey, I will share my daily progress, the knowledge I acquire, and the implementations developed during each stage of the challenge.
